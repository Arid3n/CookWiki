## Technique Selection

**Approach:** AI-Recommended Techniques

**Recommended Techniques:**

- **What If Scenarios:** Removes all constraints to break the standard "recipe app" mindset and generate radical concepts.
- **Cross-Pollination:** Steals mechanics from different industries (gaming, dating, finance) to apply to CookWiki for highly unique features.

## Technique Execution Results

The user actively curated the generated ideas, narrowing down the massive list to a core set of highly desirable features focused on deep recipe customization and culinary utility.

### Curated Feature Set
1. **Recipe Forking:** Allowing users to duplicate an existing recipe from the global feed, tweak ingredients/steps, and save it as their own personalized variant.
2. **Smart Ingredient Substitutor:** Tapping a missing ingredient allows the AI to scan the user's pantry and suggest valid substitutes, automatically rewriting the recipe and macros.
3. **Dynamic Portion Scaling:** A slider to adjust the number of servings, multiplying all ingredient amounts accordingly (requires adding a 'servings' field to the recipe schema).
4. **Recipe Playlists (Cookbooks):** Grouping recipes into custom folders or collections based on common factors (e.g., "Date Night", "High Protein").
5. **Step-by-Step "Story Mode":** A full-screen, distraction-free reading mode for cooking where each step takes up the whole screen to prevent screen-sleep and improve readability.
6. **Macro Contribution Visualizer:** A visual breakdown (like a pie chart) showing exactly which ingredients are contributing the most to the total fat, protein, and carbs of the recipe.
